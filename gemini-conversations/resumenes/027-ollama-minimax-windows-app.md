## Tema
Consultas técnicas sobre límites de modelos de IA (OpenCode/MiniMax/Kimi), diseño de logo, configuración de Windows App en Mac (trackpad, teclado, audio/webcam) y URLs de transcripción.

## Decisión clave
Se identificaron los costos y límites de peticiones de modelos de IA, se definieron especificaciones para el logo Jaroj y se establecieron los métodos de configuración para periféricos y redirección de dispositivos en Windows App.

## Datos relevantes
- **OpenCode Go**: $12/5h, $30/semana, $60/mes.
- **MiniMax M2.5**: ~15.900 peticiones/semana.
- **Kimi K2.5**: ~4.630 peticiones/semana.
- **Logo Jaroj**: Circular, J estilizada, azul corporativo, detalles de circuito, fondo blanco.
- **Windows App Mac**: Cambio de escritorios con trackpad (3-4 dedos) o Control+Flechas.
- **Captura de pantalla**: Cmd+Shift+4 (Mac) o Cmd+Shift+S (Windows en RDP).
- **Teclado Logitech**: Uso de Logi Options+ para reasignar teclas.
- **Audio/Webcam**: Configuración de Windows App para usar dispositivos locales del PC remoto.
- **URLs Transcripción**: alterna.carsharing.coop, ehcoche.carsharing.coop, ekiwi.carsharing.coop, odoo.carsharing.coop, pod.carsharing.coop
