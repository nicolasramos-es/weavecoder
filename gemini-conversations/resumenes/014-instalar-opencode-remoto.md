## Tema
Instalación y configuración de OpenCode para acceso remoto, evaluando métodos de conexión.

## Decisión clave
Se compararon dos enfoques para la conexión remota: el uso de túneles SSH frente al modo "serve" nativo, determinando las implicaciones de cada uno para la seguridad y facilidad de acceso.

## Datos relevantes
- Herramienta: OpenCode (entorno de desarrollo).
- Usuario: Nicolás Ramos.
- Métodos comparados: Túnel SSH vs. Modo Serve.
- Contexto: Configuración para uso remoto.
