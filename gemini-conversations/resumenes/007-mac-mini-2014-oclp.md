## Tema
Instalación de macOS moderno en un Mac Mini 2014 utilizando OpenCore Legacy Patcher (OCLP).

## Decisión clave
Se recomienda instalar macOS Sequoia como la versión más óptima para este hardware.

## Datos relevantes
- Hardware: Mac Mini 2014
- Herramienta: OpenCore Legacy Patcher (OCLP)
- Versión recomendada: macOS Sequoia
