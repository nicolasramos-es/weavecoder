## Tema
Automatización de la copia de seguridad de carpetas locales hacia un NAS Synology utilizando rsync y el Programador de Tareas de macOS.

## Decisión clave
Implementar un script rsync ejecutado periódicamente mediante el Programador de Tareas (Task Scheduler) de macOS para mantener sincronizadas las carpetas locales con el NAS.

## Datos relevantes
- Herramienta de sincronización: rsync
- Sistema operativo cliente: macOS
- Objetivo de almacenamiento: NAS Synology
- Mecanismo de automatización: Programador de Tareas de macOS
