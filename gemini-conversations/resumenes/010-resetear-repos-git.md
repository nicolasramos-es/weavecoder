## Tema
Resolución de errores `DirtyException` en repositorios Git dentro del entorno Doodba mediante limpieza forzada.

## Decisión clave
Utilizar el comando `git reset --hard` para limpiar el estado sucio de los repositorios Git y resolver la excepción.

## Datos relevantes
- Error encontrado: `DirtyException`
- Entorno: Doodba
- Solución aplicada: `git reset --hard`
